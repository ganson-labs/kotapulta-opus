# Котапульта

Физическая игра по рисунку на тетрадном листе (`assets/napkin.jpg`): кошачья катапульта-качели на треугольной опоре, кот-помощник держит верёвку зубами, кот летит по пунктирной дуге в крепость из коробок, где на самом верху спит соня («ZZZ…»), а между коробками лежат рыбки. Задача — разбудить всех сонь.

## Запуск

```
C:\ai-tests\napkin\opus\play.cmd
```

Команда работает из PowerShell, из cmd и двойным щелчком. Игра откроется отдельным окном Chrome (если Chrome нет — Edge). Сервер не нужен, интернет тоже: собранная игра лежит в `dist/`. Если `dist/` удалить, `play.cmd` сам выполнит `npm install` и `npm run build`.

## Управление

- **Прицел и выстрел:** зажми кота в катапульте мышью (или левее катапульты), оттяни назад и отпусти. Чем дальше тянешь, тем сильнее выстрел; пунктир показывает начало траектории.
- **Суперсила в полёте:** клик или пробел. Уголёк делает рывок, Барсик — «бомбочку» вниз, Трёшка делится на трёх котят.
- **Клавиатура:** ↑/↓ — угол, ←/→ — сила, пробел — выстрел.
- **Камера:** перетаскивай пустое место, колесо мыши меняет масштаб.
- **N** — «режим салфетки»: мир превращается обратно в рисунок ручкой на тетрадном листе.
- **F** — полный экран, **M** — звук, **R** — заново, **Esc** — пауза, **H** — спрятать интерфейс (для записи видео).

## Что внутри

- 11 уровней, 3 темы (день, закат, ночь), 4 вида котов-снарядов и босс «Король-соня».
- Физика — planck.js (порт Box2D). Урон считается по скорости удара, поэтому башни стоят устойчиво, пока в них не прилетит кот.
- Вся графика векторная, рисуется кодом на Canvas. Режим салфетки построен на rough.js.
- Звук и музыка синтезируются в Web Audio: без аудиофайлов, мяуканье — формантный синтез.
- Прогресс и рекорды хранятся в `localStorage` браузера.

## Разработка

```
npm install
npm run dev      # пересборка dist/ при изменениях в src/
npm run build    # сборка dist/game.js и dist/fonts.css
npm test         # автотест уровней: устойчивость + проходимость перебором выстрелов
node tools/shot.mjs <папка> basic        # снимки игры в headless Chrome, ошибки консоли
node tools/audio-check.mjs               # проверка звука: громкость, клиппинг, утечки
tools/audio-lab.html                     # лаборатория звука: кнопка на каждый звук
```

Структура `src/`:

- `level.js` — симуляция без DOM: мир, урон, рыбки, сони, ход игры. Её же гоняет автотест.
- `levels.js` — уровни.
- `game.js` — экраны, ввод, камера, анимации.
- `renderer.js` и `draw/` — отрисовка.
- `ui.js` — интерфейс.
- `audio.js` — звук.
